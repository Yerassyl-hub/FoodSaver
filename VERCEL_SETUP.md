# 🔧 Настройка автоматического деплоя на Vercel

## Проблема:
Vercel CLI требует интерактивную авторизацию через браузер, которую нельзя выполнить автоматически.

## ✅ Решение: Деплой через веб-интерфейс Vercel

### Вариант 1: Быстрый деплой (рекомендуется)

1. **Откройте:** https://vercel.com
2. **Войдите** через GitHub
3. **Нажмите:** "Add New Project"
4. **Выберите репозиторий:** `Yerassyl-hub/FoodSaver`
5. **Нажмите:** "Deploy"

**Готово!** Проект задеплоится за 1-2 минуты.

---

### Вариант 2: Автоматический деплой через GitHub Actions

Если хотите автоматический деплой при каждом push:

1. **Получите Vercel токены:**
   - Зайдите на https://vercel.com/account/tokens
   - Создайте новый токен
   - Скопируйте токен

2. **Получите Project ID и Org ID:**
   - После первого деплоя через веб-интерфейс
   - Зайдите в Settings проекта
   - Скопируйте Project ID и Org ID

3. **Добавьте секреты в GitHub:**
   - Зайдите в репозиторий: https://github.com/Yerassyl-hub/FoodSaver
   - Settings → Secrets and variables → Actions
   - Добавьте:
     - `VERCEL_TOKEN` = ваш токен
     - `VERCEL_ORG_ID` = ваш Org ID
     - `VERCEL_PROJECT_ID` = ваш Project ID

4. **Готово!** Теперь каждый push в `main` будет автоматически деплоить проект.
