# FoodSaver - Платформа для продажи еды со скидкой

Современная веб-платформа, где рестораны и пекарни выставляют еду с большой скидкой перед закрытием, а пользователи покупают её по выгодным ценам.

## 🚀 Возможности

- **Роли пользователей:**
  - **Business (Ресторан/Кафе)** - создание и управление предложениями еды
  - **Client (Покупатель)** - поиск и заказ еды со скидкой
  - **Admin (Администратор)** - модерация предложений

- **Функционал:**
  - 🍕 Управление предложениями еды (создание, редактирование, удаление)
  - 💰 Система цен: обычная цена и цена со скидкой
  - ⏰ Указание времени, до которого нужно забрать заказ
  - 📦 Система заказов (создание, подтверждение, завершение)
  - 🔍 Поиск и фильтрация по категориям
  - 💬 Встроенный чат между рестораном и клиентом
  - 🤖 AI-генерация описаний через Google Gemini
  - ✅ Система модерации предложений
  - 📊 Дашборд с управлением заказами

## 🛠 Технологии

- **React 18** - UI библиотека
- **Vite** - сборщик и dev-сервер
- **Tailwind CSS** - стилизация
- **Lucide React** - иконки
- **LocalStorage** - хранение данных (можно заменить на реальный бэкенд)

## 🔧 Настройка

### Изменение данных по умолчанию

Отредактируйте `src/utils/constants.js`:
- Добавьте новые города и регионы
- Измените категории еды
- Настройте начальных пользователей и рестораны

### Подключение реального бэкенда

Замените функции в `src/api/api.js` на реальные API вызовы:

```javascript
async getFoodOffers() {
  const response = await fetch('/api/food-offers');
  return await response.json();
}
```

## 📊 Модель данных

### FoodOffer (Предложение еды)
- `title` - название блюда
- `category` - категория (Выпечка, Горячее, Салаты, Напитки, Десерты)
- `oldPrice` - обычная цена
- `newPrice` - цена со скидкой
- `pickupTime` - время, до которого нужно забрать
- `description` - описание
- `status` - статус (available, reserved, completed, expired, pending_approval, rejected)

### Order (Заказ)
- `foodOfferId` - ID предложения
- `clientId` - ID клиента
- `restaurantId` - ID ресторана
- `status` - статус (pending, confirmed, completed, cancelled)

2. **Очистка кэша:**
   ```bash
   rm -rf node_modules
   ```
