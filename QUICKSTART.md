# 🚀 Быстрый старт

## Установка и запуск

```bash
# 1. Установите зависимости
npm install

# 2. Запустите dev-сервер
npm run dev
```

Приложение откроется автоматически на `http://localhost:3000`

## Первый вход

Используйте один из тестовых аккаунтов:

- **Админ:** `admin@test.com` / `admin`
- **Донор:** `cafe@test.com` / `123`
- **Получатель:** `fond@test.com` / `123`

## Что дальше?

1. **Для донора:**
   - Создайте новый лот через меню "Создать лот"
   - Используйте AI-генерацию для описания
   - Отслеживайте статус модерации

2. **Для получателя:**
   - Просматривайте доступные лоты
   - Фильтруйте по региону и категории
   - Бронируйте нужные ресурсы
   - Общайтесь с донорами в чате

3. **Для администратора:**
   - Модерируйте новые лоты
   - Одобряйте или отклоняйте публикации

## Настройка AI

1. Получите API ключ: https://makersuite.google.com/app/apikey
2. Войдите в приложение
3. Перейдите в "Настройки"
4. Вставьте ваш ключ

## Проблемы?

- **Ошибки при установке:** Удалите `node_modules` и `package-lock.json`, затем `npm install`
- **Не работает AI:** Проверьте интернет и валидность API ключа
- **Сброс данных:** Используйте кнопку "Сброс БД" в боковом меню
